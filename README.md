# AI 女友聊天網頁

## 快速開始
1. 安裝 Python 3.10 以上
2. Windows 雙擊 `run.bat`（Mac/Linux 執行 `./run.sh`），第一次會自動安裝套件並建立 `.env`
3. 打開 `.env` 填入模型設定（填 `LLM_PROVIDER=mock` 可以不接模型先試介面）
4. 重新執行，瀏覽器開 http://localhost:8000

建議用 Chrome / Edge（語音輸入需要）。

## 檔案
| 檔案 | 用途 |
|---|---|
| `persona.yaml` | 人設：名字、個性、說話方式、作息、聲音 |
| `persona_mature.txt` | 成人模式的補充人設（自行撰寫） |
| `.env` | 模型 API 設定 |
| `data/memory.db` | 對話與長期記憶（刪掉就重來） |

## 功能
- 像 LINE 的聊天介面：已讀、輸入中、一次傳好幾則、收發音效
- 語音回覆：Edge 台灣女聲（免費免金鑰），連不上時改用瀏覽器內建語音
- 語音輸入 🎙 ＋ 通話模式（她講完自動聽你說）
- 長期記憶：每 16 則訊息自動整理她記得你的事，可在選單中刪除
- 心情與好感度：會影響她的語氣
- 時間感：知道現在幾點、星期幾、你多久沒來
- 主動傳訊息：你 8–20 分鐘沒說話她會來找你（網頁要開著）
- 成人模式：`.env` 填了 MATURE_* 才會出現，切換到另一個模型

## 模型建議
- 日常聊天：GPT-4o-mini、Gemini Flash、DeepSeek 都便宜好用；中文口語要自然，模型大一點效果明顯較好
- 本機 Ollama：`ollama pull qwen2.5:14b`，再把 `.env` 指向 `http://localhost:11434/v1`

# 純網頁版（`docs/` 資料夾）

不用裝 Python，打開網頁就能聊。所有東西（金鑰、對話、記憶）都只存在你自己的瀏覽器裡。

## 使用方式
- **在電腦上直接開**：用瀏覽器打開 `docs/index.html`
- **放上 GitHub Pages**：repo 的 Settings → Pages → Source 選 `main` 分支、`/docs` 資料夾（免費方案需要 repo 是公開的；公開的只有程式碼，金鑰和對話不會外流）

第一次打開後，點右上角 ⋯ →「模型設定」填入 API 網址、金鑰、模型名稱。

## 和 Python 版的差別
| | Python 版 | 純網頁版 |
|---|---|---|
| 安裝 | 需要 Python | 不用 |
| 人設 | `persona.yaml` | `docs/persona.js` |
| 語音 | Edge 神經語音 | 瀏覽器內建（用 **Edge 瀏覽器**才有自然的台灣女聲） |
| 記憶 | 存在電腦的資料庫 | 存在瀏覽器；可在設定裡匯出 / 匯入，搬到別的裝置 |

## 注意
- 有些 API 不允許從瀏覽器直接呼叫（會出現 CORS 錯誤）。OpenAI、OpenRouter 可以；本機 Ollama 要先設定環境變數 `OLLAMA_ORIGINS=*`
- 清除瀏覽器資料會連記憶一起清掉，重要的話記得定期匯出
