# AI 女友聊天網頁

## 快速開始
1. 安裝 Python 3.10 以上
2. Windows 雙擊 `run.bat`（Mac/Linux 執行 `./run.sh`），第一次會自動安裝套件並建立 `.env`
3. 打開 `.env` 填入模型設定（填 `LLM_PROVIDER=mock` 可以不接模型先試介面）
4. 重新執行，瀏覽器開 http://localhost:8000

建議用 Chrome / Edge（語音輸入需要）。

## 檔案
| 檔案 | 用途 |
|---|---|
| `persona.yaml` | 人設：名字、個性、說話方式、作息、聲音 |
| `persona_mature.txt` | 成人模式的補充人設（自行撰寫） |
| `.env` | 模型 API 設定 |
| `data/memory.db` | 對話與長期記憶（刪掉就重來） |

## 功能
- 像 LINE 的聊天介面：已讀、輸入中、一次傳好幾則、收發音效
- 語音回覆：Edge 台灣女聲（免費免金鑰），連不上時改用瀏覽器內建語音
- 語音輸入 🎙 ＋ 通話模式（她講完自動聽你說）
- 長期記憶：每 16 則訊息自動整理她記得你的事，可在選單中刪除
- 心情與好感度：會影響她的語氣
- 時間感：知道現在幾點、星期幾、你多久沒來
- 主動傳訊息：你 8–20 分鐘沒說話她會來找你（網頁要開著）
- 成人模式：`.env` 填了 MATURE_* 才會出現，切換到另一個模型

## 模型建議
- 日常聊天：GPT-4o-mini、Gemini Flash、DeepSeek 都便宜好用；中文口語要自然，模型大一點效果明顯較好
- 本機 Ollama：`ollama pull qwen2.5:14b`，再把 `.env` 指向 `http://localhost:11434/v1`
